# Week 3: Microinteraction Deliverable

## Project Overview
Microinteraction prototype submission for Week 3.

NOTES
- Interactive Microinteraction 1: Button Press Feedback ("Add Plant")
The Moment: A hover interaction on the button changes the colour and look with a glass effect. On click, the page transitions from the Empty Garden state by clicking the "Add Plant" button.
Communication Goal: Make the button feel physically interactive, confirming the system received the action before navigating.

- Interactive Microinteraction 2: The Loading State
The Moment: Tapping the “Add plant” button on the previous page smoothly transitions into the loading state on the next page.
Communication Goal: Validate the adding process. Visual explanation: "Kindly wait while we load the plant options you can add”.

- Interactive Microinteraction 3: Transition that Actually Communicates State Addition
The Moment: Plant card gets loaded with a small “add button” that you can click to add that plant. On click, the button transitions to the page where you can confirm and save the plant details. Clicking the “Save Plant” button on the new page triggers a “saved successfully” pop-up that takes you to the final page where you can see the newly added plant.
Communication Goal: Create spatial continuity. Users need to understand where the plant was just placed and see the dashboard list expand with new item updates. This visual anchor reduces "where is it?" scrolling.
